# 🤖 AI Chat Application – LLM API

An interactive AI Chat Application built using Python, Google Gemini LLM API, and Streamlit as part of the Codomax Digital Internship – Module 3.

## 📌 Project Overview

This project demonstrates how to integrate an LLM API into a practical conversational AI application.

Users can enter questions and receive AI-generated responses through a simple and responsive web interface.

## 🚀 Features

- 🤖 Google Gemini LLM API integration
- 💬 Interactive AI chat
- 🧠 Conversation history
- ⚙️ Custom system instructions
- 🔐 Secure API key handling using Streamlit Secrets
- 🛡️ Error handling
- ⏱️ API request timeout handling
- 📊 Basic API usage tracking
- 📄 Structured JSON responses
- 📱 Responsive Streamlit interface

## 🛠️ Technologies Used

- Google Gemini API
- REST API
- Streamlit

## ▶️ Run Locally

Install the required packages:

    pip install -r requirements.txt

Run the application:

    streamlit run app.py

## 🔐 API Key Setup

The Gemini API key is stored securely using Streamlit Secrets.

Never upload your API key to GitHub.

For Streamlit deployment, add the following to Streamlit Secrets:

    GEMINI_API_KEY = "your_api_key_here"
