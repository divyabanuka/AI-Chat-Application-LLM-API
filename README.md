## 📌 Project Overview

This project demonstrates how to integrate a Large Language Model (LLM) API into a real-world conversational AI application.

Users can enter questions in the chat interface and receive AI-generated responses from the Google Gemini API.

The application maintains conversation history and supports custom AI instructions, error handling, API usage tracking, and structured responses.

## 🔄 How It Works

1. User enters a question in the chat interface.
2. The application sends the request to the Gemini LLM API.
3. Gemini processes the request.
4. The AI-generated response is received.
5. The response is displayed in the Streamlit interface.
6. Conversation history is maintained for continued interaction.

## 🔐 API Key Security

The Gemini API key is not stored in the GitHub repository.

For the deployed Streamlit application, the API key is securely stored using Streamlit Secrets.

Example:

GEMINI_API_KEY = "your_api_key_here"

⚠️ Never upload a real API key to GitHub or share it publicly.

## ▶️ Run Locally

### 1. Clone the repository

git clone https://github.com/divyabanuka/AI-Chat-Application-LLM-API.git

### 2. Open the project

cd AI-Chat-Application-LLM-API

### 3. Install dependencies

pip install -r requirements.txt

### 4. Configure your Gemini API key

Create:

.streamlit/secrets.toml

Add:

GEMINI_API_KEY = "your_api_key_here"

### 5. Run the application

streamlit run app.py
